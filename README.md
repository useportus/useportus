## About Portus

Portus develops focused tools for WordPress and WooCommerce stores.

Our plugins are designed for practical store operations: clearer navigation, faster buying flows, responsive interfaces, and controls that work well across desktop and mobile.

Each product has a Free edition for the WordPress.org ecosystem and a Pro edition for stores that need more advanced features, private updates, and dedicated licensing.

## Products

### Portus Cart for WooCommerce

A responsive AJAX side cart that lets customers review items, update quantities, apply coupons, and continue to checkout without leaving the current page.

- Floating cart button and menu/header triggers
- AJAX quantity updates, coupon controls, and item removal
- Responsive, mobile-first interface
- Theme compatibility controls
- Free edition on WordPress.org and a separate Pro edition

[View Portus Cart →](https://useportus.com/cart)

### Portus Header

A responsive and customizable WordPress header built for branded navigation.

- Native WordPress menus and submenu support
- Desktop and mobile logo controls
- CTA button, sticky header, shortcode, and automatic display modes
- Mobile navigation drawer
- Visual controls for colors, navigation, CTA, and compatibility
- Free edition on WordPress.org and a separate Pro edition

[View Portus Header →](https://useportus.com/portus-header/)

## Open Source

Public repositories contain only the Free editions distributed through WordPress.org.

Commercial Pro editions are distributed separately through Portus, with private licensing and update delivery.
